# Wallet Education

Protótipo de uma plataforma de **educação financeira para estudantes**, pensada para ser usada por escolas. O aluno se cadastra pela escola, escolhe um plano e aprende sobre dinheiro jogando.

## Telas

- **Login** e recuperação de senha
- **Cadastro** em duas etapas, com escolha da escola
- **Planos** e pagamento (escolha da forma de pagamento e tela de Pix)
- **Jogo "Tabuleiro da Riqueza"**: o objetivo é chegar ao fim do tabuleiro com o máximo de dinheiro possível

Todas as telas estão em `frontend/Wallet Education/`.

## Tecnologias

- HTML
- CSS

## Como abrir

Não precisa instalar nada: abra os arquivos `.html` direto no navegador, começando pela página de login em `frontend/Wallet Education/Pagina Login/PaginaLogin.html`.
